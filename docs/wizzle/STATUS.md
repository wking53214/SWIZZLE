## Key Design Decisions Implemented

1. **Oracle Independence**: Each oracle is a static method that takes repo_path
   - Cannot access Ghost's conclusion
   - Cannot read WIZZLE's ground-truth labels
   - Results are independently verifiable

2. **Semantic Model Separation**:
   - `SemanticTruth`: Ground truth (independent of Ghost)
   - `GhostObservation`: What Ghost reported
   - `ExperimentResult`: Complete experiment record
   - All three are distinct types

3. **Evidence Provenance Tracking**:
   - CONSTRUCTED: Generated by WIZZLE
   - OBSERVED: From actual repository
   - DERIVED: Computed from other evidence
   - TARGET_REPORTED: Ghost's finding
   - DECLARED: Stated in test setup
   - HISTORICAL: From git history
   - UNASKABLE: Cannot determine

4. **CLI Early**: Not waiting for full framework
   - Users can run `python -m wizzle inspect <repo>` now
   - Demonstrates oracle execution
   - Provides foundation for experiments
